# Master Documentation Reference

Store the previously generated 90–150 page product/technical documentation here as:

```text
reference/PROJECTPACK_MASTER_DOCUMENTATION.md
```

That document should be treated as broad product context. The `docs/` directory remains the operational implementation specification.

When a conflict appears:

1. explicit current user instruction wins,
2. `AGENTS.md` applies as persistent repository guidance,
3. detailed current `docs/` requirements define implementation behavior,
4. the long reference document is used for context and rationale.
