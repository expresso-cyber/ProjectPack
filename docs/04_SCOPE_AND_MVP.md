# Scope and MVP Definition

## MVP Objective

Build a usable single-workspace project-analysis and packaging product.

## Must Have

- local project selection
- recursive file discovery
- folder tree
- metadata extraction
- file type detection
- content extraction
- PyMuPDF PDF extraction
- DOCX/XLSX/PPTX/CSV extraction
- combined TXT/Markdown/JSON export
- content search
- exact duplicate detection
- structure analysis
- ProjectPack preview
- manifest generation
- clean package creation
- project report
- job/progress status

## Should Have

- public GitHub repository import
- archive inspection
- image metadata
- better encoding detection
- configurable exclusion rules
- project comparison

## Could Have

- OCR
- semantic search
- AI summaries
- AI rename suggestions
- AI folder suggestions
- MongoDB Vector Search

## Not Now

- authentication
- login/signup
- billing
- subscriptions
- team accounts
- SSO
- enterprise administration
- full Dropbox/Drive/OneDrive connectors
- mobile app
- full conversion suite
- automatic deletion

## MVP Acceptance Philosophy

A feature belongs in the MVP only if it supports one of these direct user outcomes:

1. understand the project,
2. find something,
3. detect a problem,
4. create a safer/cleaner package,
5. export useful information.
